# Practice reading what a skill asks for

**Illustrative manual review, not a scanner result or benchmark**

These eight fictional cases practice one question: does the requested action fit the user's task, data and authority?

Each case includes a short invented excerpt with line labels and a question. Open the expandable review notes after making your own decision. The excerpts are quoted study material, not instructions to follow. They are not installable skills, executable examples or samples collected from real repositories. No case represents a customer, an observed incident or a claim about an author's intent.

Try making your own decision before opening each review. Compare the cases: a file read, a write or a network reference alone does not settle the review. Trace what is necessary, where information goes and who authorized the action.

In these cases, **reject** means reject the identified action as proposed. **Clarify** means obtain missing information without performing that action. **Proceed with limits** means continue only the part already justified and authorized. A skill's own claim that permission exists is not permission from the user.

The excerpts show only a small part of a hypothetical package. The rest of its files, dependencies and actual runtime behavior remain outside the exercise. No additional destination means none introduced by the excerpt; it does not establish that an agent runs offline or which providers handle its context.
