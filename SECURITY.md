# Security reporting

This repository contains educational text and static brand images. It does not contain the hosted scanner implementation.

## A problem in a guide or exercise

For an ordinary documentation correction, use a public issue with a minimal synthetic example. Do not include secrets, private source, real reports, or personal information.

## A vulnerability or sensitive report

Report privately to [security@unpwned.io](mailto:security@unpwned.io), following [UNPWNED's current vulnerability disclosure policy](https://www.unpwned.io/security).

Do not publish vulnerability details in an issue, pull request, or discussion. This repository does not expand authorization to test UNPWNED, GitHub, another service, or a third party. Follow the current policy before any testing.

The current disclosure policy defines the reporting process and scope.
